# Chrono-promodoro
Une page web au design simpliste qui effectue un compte à rebours. Ce projet met en portique l’utilisation de setTimeout combinée aux Promesses en JavaScript. 

## Fonctionalités
- Démarage du chrono
- Mise en pause
- Réinitialisation
